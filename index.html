CLASSIC CONTROL
Star-Delta Starter Control Panel

A star-delta starter protects large 3-phase induction motors at start-up. Windings first connect in star (Y) — lowering starting voltage and inrush current — then switch to delta for full-power running, all timed automatically.

  • Contactors for star, delta and main line switching
  • Timer-based automatic transition from star to delta
  • Overload relay protecting the motor from sustained overcurrent
  • Neat panel wiring, indicators and start / stop control

This panel is a classic-control build focused on reliable, safe motor starting in industrial applications.

PCB DESIGN
ESP32 DevKit Board

A custom development board built to mirror the original ESP32 DevKit — engineered in KiCad with its own USB-UART and an automatic programming circuit.

  • ESP32-WROOM module with the classic 2×20 pinout — GPIO, power and boot pins
  • Onboard USB-UART bridge (CP2102-class) fed through automatic boot circuitry
  • Auto-programming: connect a cable and flash — no need to hold the BOOT button
  • Onboard 3.3 V regulation with stable power path
  • Boot / EN / RESET controls and status LED indicators

Built to spec, then pushed further — the auto-programming header makes flashing effortless compared to stock boards.
